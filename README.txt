КАК ПОЛУЧИТЬ МОД (.jar) БЕЗ УСТАНОВКИ ПРОГРАММ:

1. Зарегистрируйся на github.com (бесплатно).
2. Нажми "+" вверху -> New repository -> назови autospam -> Create repository.
3. Нажми "uploading an existing file".
4. Распакуй этот архив и перетащи ВСЁ содержимое папки autospam в окно
   (важно: папка .github тоже должна загрузиться; если не видно - включи показ скрытых файлов).
5. Нажми Commit changes.
6. Открой вкладку Actions -> подожди 3-5 минут, пока появится зелёная галочка.
7. Открой готовый запуск -> внизу Artifacts -> autospam-mod -> скачай, распакуй -> там autospam-1.0.0.jar.
8. Положи .jar в папку mods вместе с Fabric API (для 1.21.4).

В игре: правый Shift - меню.
